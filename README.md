# Tashfeen Game 

This is my first game that I made myself using Godot Engine.

It is a simple 2D puzzle game where the main goal is to move through the level, avoid different hindrances, choose the right path, and reach the end.

I made this project mainly to learn how game development actually works by building something myself instead of only watching tutorials.

## About the Game

In the game, you control the player and move around the level using the arrow keys.

There are different paths you can take, but not every path will lead you to the end. Some paths can make you lose, and sometimes it isn't immediately obvious that you picked the wrong one.

The good thing is that you can go back and try a different path.

The game is made with simple 2D tiles and currently has a basic level. I kept the first version simple because I was still learning how to build and put everything together.

## Controls

You can move the player using:

- Up
- Down
- Left
- Right

There are also movement buttons in the game.

## What I Learned

Making this game taught me a lot of things that I didn't really understand before starting it.

I learned the basics of using Godot Engine and how a game is actually put together.

Some of the things I learned while making it were:

- How to create a simple 2D game
- How to set up a game scene
- How player movement works
- How to use tiles to build a level
- How to create obstacles and hindrances
- How to make different paths in a level
- How to make different paths lead to different outcomes
- How to make the player lose when they choose the wrong path
- How to let the player move back and try again
- How to test the game and find things that don't work properly
- How different parts of a game have to work together

The biggest thing I learned was that making a game is very different from just thinking about a game. Even a simple game has a lot of small things that have to work together.
