 Tashfeen Game

Tashfeen Game is my first 2D puzzle game, made by me using the Godot Engine.

The game is about moving through obstacles, exploring different paths, and trying to reach the end. The challenge is that you may not always know which path is correct, so you have to choose carefully!

How to Play

Use the arrow keys to move your player:

- ⬆️ Up Arrow — Move up
- ⬇️ Down Arrow — Move down
- ⬅️ Left Arrow — Move left
- ➡️ Right Arrow — Move right

Explore the level, avoid the wrong paths, and try to reach the end. You can also go back and rethink your choices.

 Features

- 2D puzzle gameplay
- Simple tile-based environment
- Obstacles and path-based challenges
- Keyboard movement
- One main level
- Choices that challenge your decision-making

 Built With

- Godot Engine
- 2D game development
